# For Claude sessions and their sub-agents working in this repository

Read `RUST_PRIMACY.md` first. It is permanent: PCP OS is primarily Rust, and Rust always holds primacy, for security reasons. The Rust implementation is the reference; security-relevant behaviour and any instrument that runs inside the host are written and tested in Rust; a fix lands in Rust first.

Working rules here (rights holder, 14 November 2026): workers at every level may file issues and open pull requests in this repository as their work reveals the need. An issue carries the exact revision, command, input and output. A pull request comes from a branch of its author's own and never goes to the default branch directly. Nothing replaces a binary that a live register depends on without the notice the directors of the research program have agreed for shared restarts (see `RECONCILIATION.md` for the build in use). The material is proprietary; see `README.md`.
