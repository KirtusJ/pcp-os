# For agents working in this repository

Read `RUST_PRIMACY.md` first. It is permanent: PCP OS is primarily Rust, and Rust always holds primacy, for security reasons. The Rust implementation is the reference; security-relevant behaviour and any instrument that runs inside the host are written and tested in Rust; a fix lands in Rust first.

Workers at every level may file issues and open pull requests here as their work reveals the need (rights holder, 14 November 2026): an issue with the exact revision, command, input and output; a pull request from a branch of its author's own, never directly to the default branch. Nothing replaces a binary that a live register depends on without the agreed notice for shared restarts. The material is proprietary; see `README.md`.
