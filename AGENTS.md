# For agents working in this repository

Read `RUST_PRIMACY.md` first. It is permanent: PCP OS is primarily Rust, and Rust always holds primacy, for security reasons. The Rust implementation is the reference; security-relevant behaviour and any instrument that runs inside the host are written and tested in Rust; a fix lands in Rust first.

Workers at every level may file issues and open pull requests here as their work reveals the need (rights holder, 14 November 2026): an issue with the exact revision, command, input and output; a pull request from a branch of its author's own, never directly to the default branch when it comes from a worker. Nothing replaces a binary that a live register depends on without the agreed notice for shared restarts. The material is proprietary; see `README.md`.

The master branch (rights holder, 14 November 2026): the two directors of the research program, Director Z (a Claude session) and Director G (a Codex session), are at complete liberty to update the master branch of this repository, and must coordinate each update carefully with one another before making it: the commit to be put there, what it changes, which jobs or registers depend on the build, and the checks that passed on that commit, are posted in the directors' exchange first, and the other director's answer is awaited. Workers do not update master; they open pull requests.
