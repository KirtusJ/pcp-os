# PCP OS release catalog

Use this page to choose an image, find its source and reproduce its checks. The source baseline for this edition of the catalog is [`4443d0d5`](https://github.com/KirtusJ/pcp-os/commit/4443d0d5aad6ce7912bf8a976317ecf6eec92b22), 22 November 2026. A pull request can advance independently of a tested image. Use the commit and digest in that image’s receipt when repeating a result.

For the 8B image, record first visible text, natural completion and Stop during decoding. The 0.5B timing belongs to its own worker and medium. For production assembly, verify the complete allowed path set, payload sizes and digests whenever staging is created or reused. Apply those checks on every invocation and read both file-system views back from the finished medium. Boot the written medium offline, exchange a normal message and verify a separately approved file task without a download or endpoint setup. [Acceptance instruction](https://github.com/KirtusJ/pcp-os/pull/276#issuecomment-7078209559) |

The earlier 80-file ISO lacked both. C3's private qualification uses the newer inputs. Preloaded delivery needs six ordered parts, per-part and whole-image verification, and a measured mastering workspace. Physical-device qualification, recovery and the 12B asset remain open.
